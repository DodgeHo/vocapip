# VocaPip 产品需求文档（PRD）

- 文档版本：v0.3
- 状态：可进入产品、内容、技术与许可证评审
- 调研日期：2026-08-18
- 目标平台：Windows 10/11 x64
- 初始语言对：中文（学习辅助语言）→ 英文（目标语言）
- 内容范围：1,000 条验证词库；首次公开版 8,000 条学习就绪词目；可选约 20,000 条查询词典；全部发布内容仅使用允许商业使用与再分发的来源
- 项目代号：VocaPip / 词伴

## 1. 产品摘要

VocaPip 是一款常驻 Windows 桌面的离线单词学习桌宠。它不要求用户打开网页或登录账号，而是通过桌宠气泡，在工作的间隙呈现一个单词、一条例句和一次极短互动，并用经验值、等级、动作反馈和成长状态建立持续学习动力。

产品不是把传统单词书缩进一个悬浮窗，而是把学习拆成 10–30 秒可完成的桌面微互动：看词、结合例句判断含义、揭晓答案、反馈熟悉程度，然后继续工作。系统根据记忆状态安排复习，不采用无条件纯随机抽词。

首版完全离线运行，默认不发起任何网络请求，不包含账号、云同步、在线 AI、广告或在线埋点。内容建设分为 1,000 条验证词库、8,000 条首次公开版学习词库，以及可选的约 20,000 条离线查询词典，避免把试验数据量误当成正式产品覆盖。正式语言包不从零批量生成词库，而是整合允许商业使用的开放词表、词典与例句数据，再进行去重、分层、编辑和质检。

## 2. 背景与问题

### 2.1 用户问题

1. 上班期间打开背单词网页容易产生明显的浏览流量和页面暴露。
2. 手机学习需要切换设备，容易打断工作，也容易被其他应用带走注意力。
3. 传统单词软件一次学习流程偏长，难以利用几十秒的工作间隙。
4. 单纯随机弹词缺乏记忆规划，容易重复熟词、漏掉生词。
5. 纯工具型单词书反馈单调，难以形成长期使用习惯。
6. 用户未来可能学习不同语言对，产品不应把“中文释义 + 英文单词”写死在架构中。

### 2.2 产品机会

桌宠天然适合承担“低打扰提醒 + 情绪反馈 + 常驻入口”三个角色。将其与离线词库和间隔重复结合，可以形成区别于网页、手机 App 和传统桌面词典的轻量学习体验。

## 3. 产品目标

### 3.1 核心目标

1. 用户安装后 3 分钟内完成首次学习，不需要注册或联网。
2. 单次学习互动可在 10–30 秒内完成。
3. 桌宠常驻时不明显干扰鼠标、窗口切换和会议演示。
4. 系统能区分新词、待复习词、薄弱词和已掌握词。
5. 经验与等级能提供即时正反馈，但不干扰记忆调度的科学性。
6. 数据模型能支持未来的中文学日文、英文学日文等语言对。

### 3.2 成功指标

首版不上传指标，以下数据仅保存在本机，并可在“学习记录”中由用户查看：

| 指标 | 首版目标 |
| --- | --- |
| 首次启动至完成第一词 | 小于 3 分钟 |
| 单词卡完成时长中位数 | 小于 30 秒 |
| 默认每日目标 | 10 个有效复习/新词 |
| 7 日内有学习记录的天数 | 至少 3 天，作为产品验证目标 |
| 崩溃后学习记录丢失 | 0 条已提交记录 |
| 离线可用性 | 断网状态下所有 P0 功能可用 |
| 后台网络请求 | 默认 0 次 |

### 3.3 非目标

首版明确不做：

- 在线账号、排行榜、好友、社区或云同步。
- 在线大模型生成释义、例句或聊天。
- 完整课程、语法体系、口语评分或作文批改。
- Live2D 编辑器或复杂养成模拟器。
- 用户自制角色编辑器；首版只保留兼容角色包能力。
- 移动端和 macOS/Linux 正式支持。
- 企业监控、浏览器取词、屏幕 OCR 或读取工作内容。

## 4. 目标用户与场景

### 4.1 核心用户

需要在 Windows 办公环境中利用碎片时间学习英语，但不希望打开网页、频繁看手机或运行重型在线应用的中文用户。

### 4.2 典型场景

**场景 A：被动提醒**

用户工作 20 分钟后，桌宠轻微挥手并显示单词气泡。用户在 15 秒内看完例句、揭晓中文、选择“不会/模糊/认识/太简单”，桌宠反馈后气泡自动收起。

**场景 B：主动连学**

用户午休时双击桌宠进入“连学 5 个”，连续完成小批量学习，并查看经验条和今日进度。

**场景 C：暂时不能被打扰**

用户开始演示或会议，从托盘开启“安静 1 小时”。桌宠停止主动弹词，但仍可被拖动和手动唤起。

**场景 D：复习薄弱词**

用户打开单词本，筛选“经常不会”，查看例句与历史评分，并手动加入今日复习队列。

## 5. 设计原则

1. **低打扰优先**：学习气泡不能抢系统焦点，默认无声，不使用系统级强通知。
2. **离线优先**：运行时不依赖远程词典、在线例句或 CDN。
3. **先复习后随机**：到期复习优先，随机只负责在合适难度中选新词。
4. **一次只做一件事**：桌宠气泡一次只呈现一个词和一个主要动作。
5. **奖励努力，不惩罚遗忘**：答错仍获得少量经验；遗忘只影响复习间隔。
6. **宠物反馈服务学习**：动作、表情和奖励应解释当前学习状态，不堆叠无关养成系统。
7. **语言对可插拔**：UI 语言、已知语言、目标语言和内容包分别建模。
8. **可随时消失**：一键隐藏、穿透、暂停提醒和托盘恢复是核心能力。

### 6.3 明确排除的内容源

以下来源不进入下载、构建、测试或发布管线；获得可归档的书面商业许可后才可重新评估：

- 带 NC、Non-Commercial、仅教育、仅研究、仅个人使用、禁止衍生或禁止再分发条款的词表、词典、例句和音频。
- 许可证缺失、字段来源不明、只有仓库级许可证但数据由多处抓取聚合且无法做字段级溯源的数据集。
- British Council KVL-Chinese 等适合研究参考、但当前公开条款不足以支持打包再分发的材料。
- ECDICT 正式数据。其仓库标注 MIT，但 README 描述了早期词典文件、网络资料和抓取来源；在完成字段级来源审计前，不把其中的释义、标签、词频或例句并入商业发布语言包。
- Tatoeba 中许可未知、已删除、作者信息缺失，或任一端不在许可白名单内的句对；Tatoeba 音频首版全部排除。
- 来自商业词典、考试机构、教材、字幕站、搜索结果或网页抓取的释义、分级、例句与音频，即使单条内容看似可以访问。

### 6.4 推荐组合

- 桌宠运行时：fork OpenPet；若要闭源，则在开发开始前改用 MIT 基座或独立实现 Tauri 桌宠外壳。
- 候选词成员：NGSL + BSL + NAWL 去重后作为骨架，Wiktionary/Open English WordNet 候选用于补齐。
- 词频与排序：wordfreq 只在构建期提供排序信号；发布包保留必要的派生等级，不复制可还原其完整原始数据库的导出。
- 中文释义：优先从中文 Wiktionary 可追溯页面抽取并编辑；缺失项依据 Open English WordNet 义项由项目方自编或 AI 辅助起草，再人工确认。
- 例句：优先 Tatoeba 双方均为 CC0 的句对，其次使用许可完整的 CC BY 句对；仍缺失时由项目方自编或 AI 辅助起草并审核。
- 复习调度：ts-fsrs。
- 交互参考：TonyNa Desktop Pet 的点击、长按、悬停和角色包思路；自主行为只参考 Shijima 的公开交互表现，不复制其代码。

### 6.5 许可证决策与白名单

主方案是 OpenPet 的衍生项目，因此 VocaPip 应用代码按 GPL-3.0-or-later 兼容方式发布，并保留原项目版权和许可证说明。GPL 允许商业销售，但不允许把衍生程序作为不提供对应源码的闭源产品分发。MIT 组件可以并入 GPL 项目，但必须保留其版权声明。

首版官方语言包整体以 **CC BY-SA 4.0** 发布，同时在记录级保留原始许可证。聚合包许可证不能覆盖或抹去单条内容的原始义务。应用代码、语言包、角色素材和可选音频必须分别列出许可证，不互相借用许可结论。

构建系统采用显式许可证白名单。首版可接受：CC0-1.0、CC-BY-4.0、CC-BY-SA-4.0、Tatoeba 使用的 CC-BY-2.0-FR、MIT、Apache-2.0，以及明确的 Public Domain 标记。任何 NC、ND、研究限定、教育限定、自定义限制、未知或无法解析的许可证默认拒绝构建。

**商业化或闭源决策门：** 如果未来要求闭源发布，不得先基于 OpenPet 开发后再试图移除 GPL。此时应在立项阶段切换为 MIT Electron 基座，或仅依据公开行为重新实现 Tauri 桌宠窗口。无论应用是否商业化或闭源，官方内容包仍按其独立许可证发布。

## 7. 产品范围与优先级

### 7.1 P0：首个可用版本

1. Windows 安装包和便携版。
2. 透明、无边框、置顶桌宠窗口。
3. 拖动、右键菜单、托盘、开机启动开关。
4. 主动提醒和手动唤起两种学习入口。
5. 离线中文学英文语言包；开发与流程验证使用 1,000 条学习就绪词目，首次公开发布目标为 8,000 条学习就绪 lemma，常用短语另行计数。
6. 每个学习就绪词目至少包含：目标语词形、音标、辅助语核心释义、词性、内部学习层、一个目标语例句和辅助语译文。
7. 首次启动支持自报水平、可跳过的 3–5 分钟自适应摸底，以及手动覆盖系统推荐层级。
8. 四档自评：不会、模糊、认识、太简单；“太简单”进入已知词快速通道，而不是直接永久毕业。
9. FSRS 复习队列、新词队列、薄弱词优先和按学习表现动态调层。
10. 经验值、等级、今日目标和升级反馈；经验与能力层级分离。
11. 单词本：全部、学习中、薄弱、已掌握、已知。
12. 设置：提醒间隔、每日新词量、当前学习层、手动锁层、气泡位置、缩放、置顶、自动移动、安静模式、系统 TTS 开关。
13. 所有用户数据本地持久化；默认零网络访问。
14. 数据导出与导入，避免卸载或换机时丢失进度。
15. 语言包 schema 能同时容纳“可学习词目”和“仅查询词目”，未达到学习质量门槛的词不得进入复习队列。

### 7.2 P1：增强版本

- 拼写输入题和例句挖空题。
- 收藏、笔记、自定义单词列表 CSV 导入。
- 学习连续天数与周报。
- 多个桌宠角色和可解锁动作。
- 第二语言包：中文学日文。
- 语言包安装、卸载、版本校验和增量升级。
- 本地通知时段、工作日计划和更细的免打扰策略。

### 7.3 P2：长期方向

- 英文学日文等非中文辅助语言对。
- 本地局域网同步或用户主动选择的端到端加密同步。
- 本地模型辅助生成提示，但不得成为核心功能依赖。
- 角色创作工具、主题市场和社区语言包。
- 跨平台支持。

## 8. 核心学习循环

### 8.1 单词出现

桌宠在满足提醒条件时播放短动作，并在不抢焦点的气泡中显示：

- 目标单词。
- 音标。
- 英文例句，目标词高亮；可选“挖空模式”时以空格替代。
- 主要按钮“揭晓”。
- 次要按钮“稍后”，将该词延后 10 分钟，不记学习结果。

### 8.2 揭晓答案

点击“揭晓”后显示：

- 中文核心释义，首版最多显示两条高频义项。
- 例句中文译文。
- 四档评分按钮：不会、模糊、认识、太简单。
- 可选发音按钮。默认调用本机系统语音，不访问在线音频。

### 8.3 评分与反馈

| 用户选择 | FSRS 映射 | 宠物反馈 | 经验 |
| --- | --- | --- | --- |
| 不会 | Again | 安慰/鼓励，不出现失败羞辱 | +2 XP |
| 模糊 | Hard | 思考动作 | +4 XP |
| 认识 | Good | 开心动作 | +7 XP |
| 太简单 | Easy | 庆祝动作 | +8 XP |

拼写题答对可额外获得 +3 XP；同一词同一天的重复简单评分不重复获得完整经验，避免刷经验。

提交后立即落盘复习记录，再播放动画。即使应用在动画期间退出，记录也不能丢失。

### 8.4 下一步

- 被动提醒模式：气泡在反馈后自动收起。
- 连学模式：自动进入下一词，顶部显示“2/5”。
- 今日目标完成：宠物出现一次明显但不打扰的庆祝，并解锁当天装饰反馈。

## 9. 出词、词库与水平适配

### 9.1 队列优先级

每次请求下一个词时按以下顺序：

1. 已到期复习词。
2. 当日回答为“不会/模糊”的薄弱词，但遵守最短间隔。
3. 未达到每日新词上限时，按当前舒适层与挑战层的比例抽取新词。
4. 无可用词时，从近期已学词中做轻量巩固。

“随机”只发生在同一优先级和难度范围内部，并使用权重抽样，避免连续出现同词、同词根或过于相似的词。仅查询词目不得被随机抽入学习队列。

### 9.2 词库规模与发布口径

“1,000 词”只用于验证内容管线、学习调度、安装体积和交互闭环，不作为正式产品的完整词库承诺。内容分为三层：

| 内容层 | 规模 | 用途 | 是否进入学习调度 |
| --- | ---: | --- | --- |
| 验证词库 | 1,000 条学习就绪词目 | 内测、自动化测试、首轮人工校验和开发联调 | 是 |
| 首次公开版核心词库 | 8,000 条学习就绪 lemma | 覆盖从基础到高级阅读的主要学习路径；常用短语另行计数 | 是 |
| 可选查询词典 | 约 20,000 条高频 lemma | 离线搜索、查看释义、承接用户自定义词表 | 仅在补齐释义、层级和双语例句后才可转为学习卡 |

“学习就绪”表示该词目已通过字段完整性、许可证、释义、分层和双语例句质量门槛，可以被 FSRS 调度。查询词典可以先只有规范词形、词性、频率和基础释义，但界面必须明确标记“仅查询”，不能用不完整内容凑学习词库数量。

计数规则：

- 以 lemma 为主要计数单位，不把 runs、ran、running 等屈折变化重复计数。
- 词形变体、拼写变体和不规则变化通过 variant 记录回指 lemma。
- 固定搭配、短语动词和语义不可由单词直接推出的常用短语，可以作为独立学习词目，但不占用 8,000 lemma 配额，必须单独报告 phraseCount。
- 同形但语义、词源或学习方式显著不同的词可拆分词目；普通多词性用法优先作为同一 lemma 下的多个 sense。
- 发布清单同时报告 lemma 数、短语数、学习就绪数和仅查询数，不只报告一个容易误解的“单词数”。

### 9.3 内部学习层

首版采用产品内部层级 T1–T5，不宣称与官方 CEFR、CET、Oxford 分级逐词等价。分层只使用来源许可在白名单内的信号：NGSL/BSL/NAWL 原始顺序与交叉命中、wordfreq 现代频率、词形复杂度、义项数量、语义具体程度、例句可读性和人工校验。任何商业考试或词典分级不得被拷入正式数据。

| 层级 | 名称 | 学习就绪 lemma | 内容倾向 |
| --- | --- | ---: | --- |
| T1 | Foundation 基础 | 1,000 | 高频功能词、基础动词、生活名词和常用形容词 |
| T2 | Everyday 日常 | 1,500 | 日常场景、常见短语、基础沟通与简单叙述 |
| T3 | Work/Reading 工作与阅读 | 2,000 | 中学/CET4 常见词、办公沟通、一般新闻与说明文 |
| T4 | Upper-intermediate 中高级 | 2,000 | 抽象概念、复杂动词、专业材料中的通用词 |
| T5 | Advanced 高级 | 1,500 | 低频但高价值的高级阅读与表达词汇 |
| 合计 | 首次公开版核心词库 | 8,000 | 不含仅查询词目 |

层级是新词投放范围，不是用户身份标签。用户可以在不同技能上表现不均，系统只据此调整接下来出现哪些新词，不隐藏已经学过的内容。

### 9.4 首次水平定位

首次启动先让用户选择自报画像：刚起步、认识基础词、能读简单材料、能处理一般工作阅读、能读较复杂材料。随后提供可跳过的 3–5 分钟自适应摸底；用户也可以直接手动选择或覆盖结果。

摸底规则：

1. 从自报层级开始，每轮抽取 4 题，混合“词义选择”和“例句挖空”，避免只凭眼熟判断。
2. 单次最多 24 题、最少 12 题；达到稳定结论时提前结束。
3. 某层累计至少 8 题、答对至少 6 题、至少答对 2 道例句题，且作答时长中位数不超过 10 秒，才视为“稳定掌握该层抽样”。
4. 结果明显高于当前层时向上采样，明显低于当前层时向下采样；同一轮 2/4 时继续在当前层和相邻层补题。
5. 默认起点放在“最高稳定掌握层的下一低层”；若最高稳定层为 T1，则从 T1 开始。这样先清理漏词，再用挑战词确认上限。
6. 摸底结果显示推荐层、置信度和可调整入口，不生成语言能力证书，也不阻止用户访问其他层。

跳过摸底不影响首次 3 分钟内完成第一词：系统使用自报层级作为临时起点，并在后续真实复习中逐步校准。

### 9.5 持续自适应

系统使用滚动窗口判断“接下来投放什么新词”，不自行篡改 FSRS 对已学卡片算出的到期时间。主要信号包括：

- 最近 50 次有效复习的“认识/太简单”比例。
- lapse 率，即进入复习后再次选择“不会”的比例。
- 作答时长相对用户个人中位数的变化。
- 到期复习完成率。
- 可选的拼写或例句挖空等客观题结果；客观题权重高于纯自评。

默认新词混合为 **80% 舒适区 + 20% 挑战区**：舒适区来自当前层及以下仍未学词，挑战区来自更高一层。T5 用户的 20% 挑战位改为 T5 内较低频词或短语。

自动升层必须同时满足：最近 50 次有效复习覆盖至少 7 个学习日；成功率不低于 80%；lapse 率不高于 15%；到期复习完成率不低于 70%；并连续两个滚动窗口达标。有客观题时，客观题正确率还需不低于 75%。升层只改变新词混合，不清除低层到期复习。

当最近 30 次有效复习成功率低于 65%、lapse 率高于 30%，或同一批词连续出现明显遗忘时，暂停挑战层 3 个学习日，新词改为 80% 下一低层 + 20% 当前层。指标恢复后逐步回到标准混合。用户可以随时手动降低、提高或锁定层级；系统只给出风险提示，不强行覆盖。

### 9.6 已知词快速通道

- 摸底前可选做 20–40 词的快速熟悉度扫描；扫描本身不发 XP，只用于减少明显熟词。
- 新词首次被评为“太简单”时标记为 familiar_candidate，并在 1–3 天后用一次复核或客观题确认，不立即永久掌握。
- 复核通过后进入 known 状态并采用较长初始间隔；仍保留未来抽查和用户手动恢复入口。
- 同一词同一天重复选择“太简单”不重复获得完整经验，批量标记已知不发经验，避免刷级。
- 用户可在单词本中批量将某层词目标记为“待快速确认”，但不能未经确认直接制造大量 mastered 记录。

### 9.7 每日配额

- 默认每日新词：5。
- 默认每日目标：10 次有效学习。
- 到期复习不受新词配额限制，但单次被动提醒最多连续出现 1 词。
- 连学模式默认 5 词，可选 3/5/10。
- 当待复习积压明显时，系统优先降低新词量，而不是通过降层掩盖复习债务。

### 9.8 8,000 词组装方案

8,000 条正式词库不是由 AI 从空白生成，而是按以下来源优先级形成：

1. 导入 NGSL 2,809、BSL 1,700、NAWL 957 个原始候选，并记录来源文件版本、原始行号和原始词形。
2. 统一大小写、Unicode、连字符、英美拼写和屈折变化；按 lemma 去重，但保留一个词命中多个来源的证据。
3. 排除专名、明显过时项、缩写噪声、攻击性或成人内容、无法获得安全释义/例句的项，以及不适合中文学习者独立学习的残片。
4. 从 Wiktionary/Open English WordNet 的英语 lemma 中建立补充候选池，用 wordfreq 排序，补足三表去重和质量淘汰后的缺口。
5. 按“通用价值优先、工作场景加权、阅读价值补充”选出大于 8,000 的候选长名单；首轮建议保留 9,000–10,000 条，给审校淘汰留出余量。
6. 先映射词性和核心义项，再生成中文短释义候选。只有能确定目标义项并找到或编写合格例句的词，才进入 learning_ready。
7. 按 T1–T5 配额分层并进行边界抽检；当某层淘汰词目时，从同层候选池补位，而不是拿仅查询条目凑数。
8. 冻结 8,000 lemma 后再构建短语层。短语不占 lemma 配额，首版是否发布以及规模由独立质量报告决定。

候选入选分数至少包含：来源优先级、现代频率、跨来源支持、办公/阅读价值、词形与义项复杂度、例句可获得性、中文释义可解释性和内容风险。权重在 1,000 词验证包审校后校准，不在 PRD 中伪装成未经验证的科学常数。

### 9.9 字段来源优先级

同一词的不同字段可以来自不同开放来源，但每个字段都必须独立溯源：

| 字段 | 第一优先级 | 第二优先级 | 最终兜底 |
| --- | --- | --- | --- |
| 词库成员资格 | NGSL/BSL/NAWL | Wiktionary/OEWN lemma + wordfreq 排序 | 人工提名，但必须在至少一个白名单词典中验证存在 |
| lemma/词性/词形 | Open English WordNet | Wiktionary | 人工修订并保留修改记录 |
| 中文核心释义 | 中文 Wiktionary 可追溯条目 | 依据 OEWN 义项进行编辑翻译 | AI 辅助草稿 + 人工逐条确认 |
| 发音文本/音标 | Wiktionary 可追溯字段 | 系统 TTS 运行时发音 | 首版允许为空，不从商业词典补录 |
| 频率与排序 | NGSL 系列顺序 | wordfreq 派生分位/等级 | 人工只可处理边界，不可伪造频率值 |
| 双语例句 | Tatoeba 许可白名单句对 | 项目方自编 | AI 辅助草稿 + 人工逐条确认 |
| 内部学习层 | 开放频率与词表特征 | 例句难度和词义复杂度 | 人工边界审校 |

AI 不能决定词是否真实存在、不能作为许可证明、不能直接复制商业词典文案，也不能自动把候选提升为 learning_ready。所有 AI 辅助字段必须标记 ai_assisted=true，经过人工确认和文本相似度检查后才能发布。发布报告必须分别列出开放来源、项目自编和 AI 辅助记录数量。

### 9.10 内容构建流水线

构建命令必须可重复执行，并产出机器可读报告：

1. **fetch**：只下载锁定版本和校验和匹配的白名单来源。
2. **ingest**：把每个来源写入独立 staging 表，不在导入时丢弃原始 ID、行号、revision 或许可。
3. **normalize**：规范 lemma、词形、词性和语言代码，生成可审计的 merge 记录。
4. **candidate**：计算三表 union、交集、现代频率与候选分数，输出长名单。
5. **sense-map**：把目标词映射到 OEWN/Wiktionary 义项，避免释义与例句义项错配。
6. **example-match**：筛选 Tatoeba 句对，检查目标词形命中、翻译链、许可和难度。
7. **editorial**：编辑中文释义与缺失例句；AI 只生成待审核草稿。
8. **tier**：分配 T1–T5，执行层级配额和边界样本审校。
9. **validate**：运行 schema、重复、许可、来源链、语言识别、敏感内容、例句长度和义项一致性检查。
10. **package**：生成 SQLite、manifest、LICENSES、THIRD_PARTY_NOTICES、source-lock 和 content-report；任一未知许可记录使构建失败。

构建环境允许为获取锁定数据源和可选 AI 草稿而联网，但发布后的桌宠运行时不得依赖网络。语言包一旦构建完成，桌宠只读取本地 SQLite；用户使用过程中不调用词典网站、Tatoeba 或 AI 服务。

## 10. 经验与等级系统

### 10.1 定位

等级代表“陪伴学习投入”，不是语言能力证书。复习间隔由 FSRS 决定，等级不直接修改某个词的记忆状态。

### 10.2 升级曲线

升到下一级所需经验：

~~~text
next_level_xp = 60 + 20 * (current_level - 1)
~~~

前几级可在约 8–15 个有效互动内升级，后续逐步放缓。等级上限首版为 30，但数据模型不设硬上限。

### 10.3 等级奖励

- 解锁新的宠物反馈动作或气泡边框。
- 解锁统计页中的成长称号；更高层新词只由学习表现或用户手动选择决定，不由 XP 解锁。
- 解锁统计页中的成长纪念，不提供影响记忆算法的数值加成。
- 不设置付费货币、体力值或连续登录惩罚。

## 11. 桌宠行为规格

### 11.1 基础状态

| 状态 | 触发 |
| --- | --- |
| idle | 无交互时默认循环 |
| attention | 新学习提醒出现 |
| thinking | 用户查看答案或选择“模糊” |
| success | 选择“认识/太简单”或拼写正确 |
| encourage | 选择“不会”或拼写错误 |
| level-up | 升级 |
| moving | 用户拖动或自主移动 |
| sleeping | 安静模式或长时间无活动 |

### 11.2 鼠标行为

- 单击宠物：显示/收起当前学习气泡。
- 双击宠物：开始“连学 5 个”。
- 拖动：移动宠物；释放后保存相对屏幕位置。
- 右键：打开紧凑菜单。
- 悬停：暂停自主移动，不自动弹出学习内容。

### 11.3 右键菜单

- 学一个词
- 连学 5 个
- 打开单词本
- 安静 30 分钟 / 1 小时 / 到明天
- 鼠标穿透
- 始终置顶
- 设置
- 隐藏桌宠
- 退出

### 11.4 低打扰约束

- 气泡不抢键盘焦点，除非用户主动进入拼写题。
- 默认不播放声音。
- 全屏应用运行时暂停主动提醒。
- 鼠标在气泡区域外时，气泡不扩大点击区域。
- 鼠标穿透模式下，使用托盘或全局快捷键恢复交互。
- 多显示器切换、分辨率变化后，宠物必须保持在可见工作区。

## 12. 页面与信息架构

### 12.1 桌宠层

常驻透明窗口，只包含宠物、状态提示和学习气泡。气泡最大宽度 360 px，例句最多显示 3 行；超长内容在详情页查看，不能无限撑大桌面遮挡区域。

### 12.2 单词本窗口

采用工作型紧凑布局，不做营销首页：

- 顶部：今日完成、到期复习、新词配额、等级经验。
- 标签：今日、学习中、薄弱、已掌握、收藏。
- 列表字段：单词、核心释义、状态、下次复习、最近评分。
- 详情侧栏：完整释义、例句、词形、历史记录、重置学习状态。
- 搜索：支持目标词和辅助语言释义搜索。

### 12.3 设置窗口

设置分为：

- 学习：每日新词、每日目标、当前学习层、自动调层/手动锁层、提醒间隔、连学数量。
- 桌宠：角色、缩放、置顶、自主移动、悬停暂停、气泡方向。
- 安静模式：时间段、全屏暂停、临时暂停。
- 语言：界面语言、当前语言包、目标语言、辅助语言。
- 数据：导出、导入、重置进度、语言包信息与许可证。
- 系统：开机启动、快捷键、系统 TTS、硬件加速开关。

### 12.4 托盘

托盘菜单始终可恢复被隐藏或鼠标穿透的桌宠，并显示今日进度。退出必须通过托盘或右键菜单明确触发；关闭设置窗口不退出应用。

## 13. 多语言与内容包设计

### 13.1 概念分离

- UI locale：应用界面语言，例如 zh-CN。
- Base language：用户用来理解释义的语言，例如 zh-CN 或 en。
- Target language：正在学习的语言，例如 en 或 ja。
- Language pack：某个 Base→Target 方向的离线内容包。

“中文学日文”和“英文学日文”是两个不同内容包，可以共享日文词条 ID，但释义和例句翻译不同。

}
~~~

验证包使用独立的 packId（例如 zh-CN__en.pilot.1000），不得与正式核心包共用版本号或在界面上冒充完整词库。查询扩展包单独报告 lookupOnlyCount。

### 13.3 内容质量规则

- 每个学习就绪词目必须有核心释义、词性、内部学习层和至少一组双语例句；任一必需字段缺失时只能作为仅查询词目。
- 例句优先 5–14 个英文单词；T1–T2 避免不必要的复杂从句，T3–T5 可随层级增加句法复杂度。
- 例句避免无必要的专名、政治敏感内容、成人内容、歧义翻译和无法脱离上下文理解的指代。
- 目标词应以正确词形出现在例句中；词形变化必须通过 variant 关联到 lemma。
- 释义只展示适合当前层级的高频义项，不一次堆出完整词典；完整义项可在详情页展开。
- 构建期执行重复、缺字段、非法字符、长度、层级分布、来源许可、例句目标词命中、语言识别、义项一致性、敏感内容和人工抽检。
- 每次发布输出 content-report.json，列出各层数量、学习就绪率、仅查询数、来源覆盖率、原生/自编/AI 辅助字段数量、许可证分布、自动校验失败数和人工抽检结果。
- 任一展示字段若无法追溯到白名单开放来源或已审核的项目自编记录，该词目不得标记为 learning_ready。

### 13.4 来源、许可与署名交付物

每个官方语言包必须包含以下离线文件，并能从设置页“语言包信息与许可证”打开：

- **LICENSES.md**：语言包整体许可、各来源许可全文或规范链接、署名格式和修改说明。
- **THIRD_PARTY_NOTICES.md**：项目、作者、数据集版本、版权声明和所用字段。
- **source-lock.json**：下载 URL、发布日期或 revision、文件名、SHA-256、获取日期和导入器版本。
- **content-report.json**：记录数量、来源覆盖率、许可证分布、AI 辅助比例、审校覆盖和失败项。

记录级 provenance 不面向普通学习界面堆叠展示，但在单词详情“内容来源”中可查看。导出用户学习数据时不必重复导出整套第三方内容；导出自定义词表时必须保留随词条附带的来源和许可字段。

官方构建不得静默接受新许可证。新增 SPDX 或自定义许可标识必须通过一次人工许可评审并更新白名单测试。CI 对未知许可、缺少来源 ID、缺少作者归属、source-lock 校验和变化和许可文本缺失执行 fail closed。

### 14.2 状态定义

- new：从未学习。
- familiar_candidate：首次被判断为明显熟悉，等待短期复核。
- known：通过快速通道确认的既有熟词，采用较长间隔但仍可抽查。
- learning：处于短期学习步骤。
- review：进入正常间隔复习。
- weak：最近出现 Again/Hard 或多次遗忘。

## 15. 技术架构建议

### 15.1 总体架构

~~~text
Tauri Shell
├─ Pet Window（透明常驻窗口）
├─ Library/Settings Window（普通应用窗口）
├─ Tray & Global Shortcut
├─ Learning Engine
│  ├─ Queue Selector
│  ├─ Placement & Tier Adapter
│  ├─ FSRS Adapter
│  ├─ XP/Level Service
│  └─ Reminder Scheduler
├─ Content Repository（只读语言包 SQLite）
├─ User Repository（可写用户 SQLite）
└─ Import/Export Service
~~~

### 15.2 数据存储

- 语言包数据库只读，便于版本升级和校验。
- 用户数据库单独存储，避免语言包更新覆盖学习进度。
- 所有评分采用事务写入：StudyCard、ReviewLog、XP 同事务提交。
- 导出格式使用带 schemaVersion 的 ZIP，包含用户数据库快照和 manifest。

### 15.3 网络策略

- P0 构建中不引入运行时网络客户端依赖。
- OpenPet 原有 HTTP API 默认关闭；如保留代码，必须由用户显式开启并仅监听 127.0.0.1。
- 更新检查默认关闭或在 P1 作为明确可选项。
- 自动化测试应在阻断网络的环境中跑完核心学习流程。

### 15.4 复用边界

从 OpenPet 直接复用或改造：窗口、托盘、宠物渲染、动作状态、设置框架、多语言 UI、角色包加载和 Windows 打包。

新增独立模块：语言包仓库、学习队列、FSRS 适配器、XP 服务、提醒策略、单词本和数据导入导出。

不要把学习逻辑塞入 PetWindow 组件；桌宠层只消费“当前卡片”和“宠物状态”事件。

## 16. 非功能需求

### 16.1 性能

- 冷启动到桌宠可见：目标小于 3 秒，机械硬盘环境小于 6 秒。
- 空闲 CPU：平均低于 1%。
- 主动动画 CPU：普通办公设备平均低于 5%。
- 内存：目标低于 150 MB，硬上限 250 MB。
- 单词查询或下一词计算：95 分位小于 100 ms。
- 用户数据库 10 万条复习日志下，单词本首次打开小于 1 秒。

### 16.2 稳定性

- 异常退出后已提交学习记录不丢失。
- 升级前自动备份用户数据库。
- 语言包损坏时回退到内置核心包，并显示本地错误说明。
- 多显示器拔插后不出现无法找回的窗口。

### 16.3 可访问性

- 所有核心操作支持键盘。
- 评分按钮有文字，不只依赖颜色。
- 提供减少动画模式。
- 字号、桌宠缩放和气泡缩放独立可调。
- 颜色对比满足常用正文可读要求。

### 16.4 隐私与安全

- 默认不联网、不采集、不上传。
- 不读取浏览器、剪贴板、当前文档、键盘输入或屏幕内容。
- 数据页明确展示本地数据目录与导出入口。
- 导入包先校验 manifest、schema、文件类型和大小；不执行脚本。

## 17. 首次启动流程

1. 显示桌宠，并在旁边出现不超过三屏的设置气泡。
2. 选择学习目标：中文学英文（首版唯一可用，其他方向不展示不可用的假入口）。
3. 选择自报画像：刚起步 / 认识基础词 / 能读简单材料 / 能处理一般工作阅读 / 能读较复杂材料。
4. 选择“快速开始”或“做 3–5 分钟摸底”；摸底可随时结束并使用当前推荐结果。
5. 选择提醒节奏：15 / 30 / 60 分钟 / 仅手动；默认 30 分钟。
6. 显示推荐学习层、80/20 新词混合说明和手动调整入口。
7. 立即学习一个示例词；完成评分后进入正常状态，并提示托盘和安静模式入口。

首次启动不要求选择角色、创建账户或阅读长篇教程。选择快速开始时仍应在 3 分钟内完成第一词；选择摸底时，“3–5 分钟”单独计入可选测评时间。

## 18. 异常与边界场景

- **没有到期复习且达到新词上限：** 显示“今天计划完成”，允许手动巩固。
- **语言包缺失：** 加载内置最小演示包并引导从本地文件安装正式包。
- **系统没有可用英文语音：** 隐藏或禁用发音按钮，说明需安装 Windows 语音包。
- **全屏应用：** 暂停主动气泡，不改变复习到期时间。
- **电脑休眠后恢复：** 不补发所有错过提醒，只在新的间隔周期触发一次。
- **系统时间被修改：** 记录异常并限制极端间隔，避免大量卡片同时失真。
- **当天重复学习同词：** FSRS 正常记录，但 XP 按递减规则发放。
- **用户选择“太简单”过多：** 进入已知词快速通道并安排复核；批量扫描和重复 Easy 不发完整 XP，也不直接制造永久掌握记录。

## 19. 验收标准

### 19.1 功能验收

- 断网安装并启动后可完成首次学习。
- 桌宠可拖动、置顶、隐藏、穿透并从托盘恢复。
- 验证包的 1,000 条学习就绪词目均能展示完整 P0 字段，并可被正常调度。
- 用户可跳过摸底、自报起点、完成 12–24 题自适应摸底，或手动覆盖推荐层。
- 使用固定测试数据时，摸底能提前结束，并按“最高稳定层的下一低层”给出可复现结果。
- 新词选择符合 80% 舒适区 / 20% 挑战区；升层或降层不删除任何已到期低层复习。
- “太简单”首次只进入 familiar_candidate，复核后才进入 known；批量确认和重复 Easy 不能刷取完整 XP。
- 四档评分正确生成不同的下次复习结果。
- 评分后重启应用，进度、XP、学习层和下次复习时间保持一致。
- 达到升级条件时只触发一次升级奖励。
- 单词本分类与实际学习状态一致。
- 导出后清空数据，再导入可恢复全部学习记录和定位结果。
- 切换显示器和 DPI 后桌宠仍在可见区域。
- 开启安静模式后不再主动弹词，手动学习仍可用。

### 19.2 内容验收

验证包：

- 1,000/1,000 条均为学习就绪词目，具备核心释义、词性、内部学习层和双语例句。
- 用于验证全部自动检查、分层逻辑、词形回指和许可证追溯，不作为公开版覆盖范围宣传。

首次公开版核心词库：

- 学习就绪 lemma 达到 8,000，层级分布为 T1 1,000、T2 1,500、T3 2,000、T4 2,000、T5 1,500；短语数量另行报告。
- 8,000/8,000 条具备中文核心释义、词性、内部学习层和至少一组双语例句。
- T1 的 1,000 条逐条人工审校；T2–T5 按层级、词频和来源分层抽检，另行人工抽检不少于 1,000 条，并覆盖全部自动校验告警项。
- 自动校验无重复主键、孤立释义、孤立例句、未回指词形、目标词未命中例句、义项错配、未知许可证、NC/ND/研究限定许可证和来源链断裂。
- 8,000/8,000 条 lemma 的成员资格可追溯到 NGSL/BSL/NAWL，或 Wiktionary/OEWN 候选池与 wordfreq 排序证据；AI 不作为词目存在性来源。
- 每个发布字段均存在已批准的 FieldProvenance；Tatoeba 英文句和中文翻译分别具备 sentence id、作者与许可证。
- 所有 ai_assisted=true 的释义和例句均经过逐条人工批准；未审核 AI 草稿数量为 0。
- content-report.json 的 lemma、短语、学习就绪、仅查询、各层、来源覆盖、许可分布和 AI 辅助数量与数据库实际一致。
- LICENSES.md、THIRD_PARTY_NOTICES.md、source-lock.json 能从发布包离线打开，并可追溯词表、词典与例句来源。
- 语言包中不存在 ECDICT、British Council KVL、商业词典、商业考试分级或其他排除来源的发布字段。

可选查询词典：

- 目标约 20,000 条高频 lemma；未补齐学习字段的条目必须标记为 lookup_only，搜索可见但永不进入复习队列。
- 查询词条转为学习就绪时，必须通过与核心词库相同的内容质量门槛。

### 19.3 性能验收

- 在 Windows 11 常见办公设备上连续运行 8 小时无持续内存增长。
- 空闲状态不持续写盘，不高频轮询数据库。
- 关闭网络后没有错误弹窗、卡死或功能降级。

## 20. 开发阶段与建议拆分

### 阶段 0：许可证与基座确认（2–3 天）

- 确认项目接受 GPL-3.0-or-later；商业销售与闭源发布作为两个不同决策处理。
- 固定 OpenPet 上游 commit。
- 建立数据源白名单、排除清单、LICENSES、THIRD_PARTY_NOTICES 和 source-lock 模板。
- 下载并归档 NGSL/BSL/NAWL、wordfreq、OEWN、Wiktionary/Tatoeba 的许可文本与版本信息。
- 为未知许可、NC、ND、研究限定和来源链缺失编写 fail-closed 测试。

### 阶段 1A：内容管线与学习引擎原型（5–8 天）

- 定义语言包 schema、lemma/variant 计数规则和 learning_ready 门槛。
- 构建 NGSL/BSL/NAWL + wordfreq + OEWN + Wiktionary/Wiktextract + Tatoeba 的 staging、规范化与 provenance 管线。
- 产出 1,000 条验证词库，用于联调与测试，不作为最终公开版词库。
- 接入 ts-fsrs，完成队列、评分、定位、动态调层和持久化测试。

### 阶段 1B：8,000 条开放数据整合、分层与编辑质检（建议与软件并行，4–8 周）

- 计算 NGSL/BSL/NAWL 去重后的实际 union，建立 9,000–10,000 条候选长名单并记录选入/淘汰原因。
- 使用 OEWN/Wiktionary 完成词形与义项映射，用 wordfreq 参与补齐排序，冻结 8,000 lemma 和 T1–T5 配额。
- 完成中文释义编辑、Tatoeba 双语例句匹配、缺失内容自编或 AI 辅助起草、词形回指、字段级 provenance 和自动质量检查。
- 完成 T1 全量人工审校、所有 AI 辅助字段逐条审校、T2–T5 分层抽检和全部告警项复核。
- 输出可复现语言包、来源锁定文件、许可清单和内容覆盖报告。
- 可选构建约 20,000 条仅查询词典；该项不阻塞核心学习功能上线。

### 阶段 2：桌宠学习循环（5–8 天）

- 学习气泡、揭晓、四档评分和已知词快速通道。
- 宠物状态映射、XP 和升级。
- 主动提醒、安静模式、托盘入口。

### 阶段 3：单词本与设置（4–6 天）

- 列表、筛选、详情和搜索。
- 每日目标、定位结果、自动调层、手动锁层和提醒设置。
- 导入导出与语言包信息页。

### 阶段 4：Windows QA 与发布（4–6 天）

- 多显示器、DPI、休眠恢复、开机启动、便携版测试。
- 8 小时稳定性测试与离线测试。
- 内容抽检、许可证审查和安装包发布。

软件功能可以先基于 1,000 条验证词库在约 3–5 周内完成。若有独立内容人员，8,000 条公开版内容可与软件并行，整体首发约 6–10 周；若由单人顺序完成开发、内容整理和审校，更合理的整体预估是 8–14 周。约 20,000 条查询词典不应成为首发阻塞项。

## 21. 风险与缓解

| 风险 | 影响 | 缓解 |
| --- | --- | --- |
| OpenPet GPL 与未来闭源计划冲突 | 高 | 阶段 0 做不可逆决策；闭源则改用 MIT 基座或独立实现 |
| 8,000 条核心词目的释义、例句与分层质量不一致 | 高 | 自动质量门槛、T1 全审、AI 辅助字段全审、T2–T5 分层抽检、告警项必审、版本化内容报告 |

| Tatoeba 英文句与中文翻译的作者或许可链丢失 | 高 | 两端分别存 sentence id、作者、许可和修改状态；优先 CC0 句对；未知许可直接拒绝 |

| 桌宠长期占用过高 | 高 | 选择 Tauri、降低空闲帧率、事件驱动提醒、8 小时性能测试 |
| 提醒打扰工作 | 高 | 默认 30 分钟、无声、不抢焦点、全屏暂停、一键安静 |
| 经验系统诱导刷分 | 中 | 同词 XP 衰减、XP 与记忆状态解耦、无惩罚型连续登录 |
| 纯自评或批量 Easy 导致虚假掌握 | 中 | 摸底混合客观题、Easy 延迟复核、批量扫描不发 XP、known 仍保留未来抽查 |
| 多语言扩展时 schema 重构 | 中 | 首版即拆分 UI/Base/Target/Pack，不把中文字段写死 |
| 角色素材再分发权不清 | 中 | 使用自有或明确授权素材；角色包许可证单独记录 |

## 22. 产品决策记录

1. **桌宠能做，而且适合 Windows 离线场景。** 现有开源项目已经验证透明置顶、托盘、拖动、角色包和安装打包能力，主要工作应放在学习循环与内容质量上。
2. **1,000 条是验证词库，不是正式覆盖承诺。** 首次公开版目标是 8,000 条学习就绪 lemma，常用短语另行计数；约 20,000 条查询词典作为可选扩展，不能把不完整词目计入学习词库。
3. **词库按 lemma 计数。** 屈折词形和拼写变体回指 lemma，固定短语可独立计数，发布时分别公开 lemma、短语、学习就绪和仅查询数量。
4. **能力层采用内部 T1–T5。** 它服务于内容投放，不伪装成官方 CEFR 或考试等级认证。
5. **首次定位采用“自报 + 可选短测 + 手动覆盖”。** 默认从最高稳定掌握层的下一低层开始，宁可少量清理漏词，也不直接把用户推入过难内容。
6. **持续适配采用 80% 舒适区 + 20% 挑战区。** 升降层只改变新词来源，不改变 FSRS 已生成的复习责任。
7. **首版不采用“完全随机单词”。** 采用到期复习优先、薄弱词其次、当前层与挑战层内加权随机。
8. **首版默认 fork OpenPet。** 原因是 Tauri 资源占用方向更适合长期常驻，且已有完整桌宠运行时。
9. **首版保持开源并接受 GPL。** 若这一点不能接受，技术基座必须在开发前切换。
10. **例句不在运行时生成。** 统一在构建期筛选并打包，确保离线、稳定和可审计。
11. **经验与等级不替代记忆算法或能力分级。** XP 负责动机，FSRS 负责复习时间，T1–T5 负责新词范围。
12. **已知词快速通道需要复核。** “太简单”不能立即永久掌握，批量熟词扫描也不能成为刷经验入口。
13. **音频不是硬依赖。** 首版只提供可选系统 TTS，不随包分发大体积音频。
14. **多语言从 schema 开始支持，而不是首版塞入多套内容。** 首版只发布 zh-CN→en。
15. **8,000 词不是由 AI 从零生成。** 词目成员由允许商业使用的开放词表和开放词典候选组成，AI 只协助补缺释义与例句草稿。
16. **正式发布不采用 ECDICT 和 KVL-Chinese。** 前者字段来源不足以做商业发布级溯源，后者当前公开条款不足以支持打包再分发。
17. **许可证检查采用白名单和 fail closed。** NC、ND、研究/教育限定、未知许可和来源链缺失的记录均不得进入语言包。
18. **应用代码与内容包分开许可。** OpenPet 衍生代码按 GPL，官方语言包按 CC BY-SA 4.0，并在记录级保留原许可证。
